# Marketplace Model

## Goal

Create a trusted cloud-agentic marketplace that is smaller, stricter, and more useful than broad prompt collections.

## Core model

1. Assets live in provider/domain folders.
2. Catalog JSON files index assets for machines.
3. Schemas define required metadata.
4. Tests enforce catalog consistency and secret hygiene.
5. Official documentation links anchor cloud claims.

## Curation policy

The marketplace should grow slowly with strong review. A small catalog of high-trust assets is better than a large catalog nobody should run.
