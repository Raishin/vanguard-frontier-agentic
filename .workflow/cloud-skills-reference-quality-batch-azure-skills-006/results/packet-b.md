# Packet B: Resilience BCDR and Resource Health Triage

## Targets

- `skills/azure/azure-resilience-bcdr-review`
- `skills/azure/azure-resource-health-incident-triage`

## Evidence used

Microsoft Learn documentation through the user's configured documentation MCP. No live Azure environment state was sampled.

## Findings addressed

- Resilience/BCDR guidance now separates Azure platform capabilities from workload recovery obligations, requires business-defined RTO/RPO, failover/failback separation, restore drills, accessible DR assets, and safe recovery automation.
- Resource Health triage guidance now separates Resource Health, Service Health, activity log, recent tenant-side changes, alerting, and unknown evidence instead of over-attributing provider incidents.
