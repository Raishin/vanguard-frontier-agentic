# Preflight

1. Confirm the exact target and scope from sanitized evidence.
2. Ground Azure service behavior in Microsoft Learn documentation through the user's configured documentation MCP.
3. Label any read-only configured-environment evidence as sampled evidence.
4. Verify owner, impact, approval need, rollback or disablement path, and post-action validation target.
5. Stop if evidence is missing, stale, over-broad, or secret-bearing.
