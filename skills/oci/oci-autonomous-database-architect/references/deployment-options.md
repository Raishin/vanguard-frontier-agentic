# Autonomous Database deployment options

Use this component-specific reference after loading the operations reference.

## Review dimensions

- Serverless versus dedicated Exadata changes isolation, operator control, maintenance, capacity, and cost assumptions.
- Cloud@Customer and database-at-provider models change control-plane, networking, residency, support, and operational ownership.
- Multicloud compatibility needs exact product, region, identity, network, backup, Data Guard, licensing, and support evidence.
- Do not treat marketing availability as proof that the user's subscribed region, limits, and support path are ready.
