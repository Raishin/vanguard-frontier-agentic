# Autonomous Database compatibility checklist

Use this component-specific checklist for workload fit.

- Workload type, database version, feature usage, APEX/ORDS/JSON/vector needs.
- Network path, private endpoint, DNS, wallet/TLS, client version, and egress controls.
- Backup, restore, clone, refreshable clone, Data Guard, switchover/failover, and rollback evidence.
- Data residency, encryption/key ownership, audit, Data Safe, Operations Insights, alarms, and owner model.
- Migration method, cutover window, validation queries, rollback criteria, and support escalation path.
