# Official sources

Use this reference when grounding Scaleway service behavior or confirming which specialist covers a given product area.

## Scaleway documentation

Use these as starting points for domain classification — not as proof of the user's live Scaleway state:

- https://www.scaleway.com/en/docs/ — official Scaleway product documentation
- https://www.scaleway.com/en/developers/api/ — Scaleway API reference (all products)
- https://registry.terraform.io/providers/scaleway/scaleway/latest/docs — Terraform provider resource catalog

## Grounding rule

Official documentation describes Scaleway service capabilities and API behavior. It does not confirm the user's live project configuration, active resources, quotas, or current billing state. Routing decisions must be based on signals present in the user's request, not on assumed defaults from documentation.
