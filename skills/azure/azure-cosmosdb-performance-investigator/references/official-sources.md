## Grounded insights used by this skill

- Request charge, query metrics, and partition-level metrics are more trustworthy than intuition.
- High RU and high latency are not the same failure mode.
- Hot-partition diagnosis needs partition-range and logical-key evidence, not just aggregate throttling counts.
