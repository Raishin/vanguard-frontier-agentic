## Grounding rule

Official documentation explains Huawei Cloud service behavior. It does not prove the user's current VPC configuration, ELB listener state, CFW rule set, Anti-DDoS binding, DC Gateway connection status, pricing, or operational state. Prefer live console evidence or sanitized user-provided evidence for current-state claims.
