## Grounding rule

Official documentation explains Alibaba Cloud SSL Certificate Service behavior and feature availability. It does not prove the user's current certificate status, DNS validation record presence, deployment binding state, or CloudMonitor alert configuration. Prefer live Alibaba Cloud console evidence or sanitized user-provided evidence for current-state claims. Certificate auto-renewal status in the console reflects the configuration setting, not proof that the DNS validation record is currently resolvable — verify separately.
