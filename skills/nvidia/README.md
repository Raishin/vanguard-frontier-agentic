# NVIDIA Skills

Cert-anchored skills covering NVIDIA's certification programs (NCA / NCP)
and the operational realities of running NVIDIA-accelerated infrastructure.

Each skill aligns to one or more current NVIDIA certifications:

- `nvidia-ai-infrastructure-operations` — NCA-AIIO, NCP-AII
- `nvidia-ai-operations-day2` — NCP-AIO
- `nvidia-ai-networking-fabric-review` — NCP-AIN
- `nvidia-generative-ai-platform-review` — NCA-GENL, NCA-GENM, NCP-GENL
- `nvidia-agentic-ai-platform-review` — NCP-AAI
- `nvidia-gpu-operator-kubernetes-hardening` — cross-cutting (no 1:1 cert)
- `nvidia-ngc-nim-supply-chain-governor` — cross-cutting (no 1:1 cert)

Out of scope (intentionally): `NCA-ADS`, `NCP-ADS`, `NCP-OUSD`. The data
science track and OpenUSD are not aligned with this repo's cloud and
zero-trust focus. Add them when there is a real consumer ask, not before.
