# Official sources

Use this reference only when grounding IONOS Cloud service behavior, routing logic, or the specialist agent taxonomy.

## IONOS Cloud documentation

Use these as starting points for understanding platform capabilities, not as proof of the user's live IONOS configuration:

- https://docs.ionos.com/cloud/ — official product documentation covering all IONOS Cloud services
- https://api.ionos.com/docs/ — REST API reference for authentication, resource operations, and endpoint inventory
- https://registry.terraform.io/providers/ionos-cloud/ionoscloud/latest/docs — Terraform provider resource and data source reference

## Grounding rule

Official IONOS documentation describes platform capabilities and service behavior. It does not prove the user's current datacenter state, resource inventory, active configurations, pricing, or quota posture. Prefer live evidence or sanitized user-provided evidence for any claim about the user's specific IONOS Cloud environment. When live tooling is unavailable, state this explicitly and fall back to documentation-based reasoning labeled as such.
