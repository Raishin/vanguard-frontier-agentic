# Official sources

Use this reference only when grounding IONOS Cloud pricing, billing behavior, or compute sizing options.

## IONOS Cloud billing and pricing documentation

Use these as starting points, not as proof of the user's specific contract terms or actual resource costs:

- https://docs.ionos.com/cloud/getting-started/billing-and-contract — billing concepts, contract tiers, and hourly vs. monthly pricing models
- https://cloud.ionos.com/prices — current public pricing for compute, storage, managed services, and networking
- https://docs.ionos.com/cloud/compute-engine/virtual-servers — compute sizing options, core and RAM configurations, and storage types
- https://docs.ionos.com/cloud/ — general platform reference for service catalog and available resource types

## Grounding rule

Official IONOS pricing documentation reflects published public rates. Actual charges depend on the user's specific contract tier, reserved capacity agreements, and usage pattern. Do not quote pricing as a certainty — label it as `documentation-based` and note that the user's actual bill may differ. Prefer user-provided billing export or cost dashboard evidence for specific saving estimates.
