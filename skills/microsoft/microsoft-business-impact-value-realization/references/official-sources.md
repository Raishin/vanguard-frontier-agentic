# Official sources

Use this reference only when you need source grounding for Microsoft 365 / Copilot adoption measurement and value-realization behavior.

## Microsoft Learn documentation

Use these as starting points, not as proof of the user's actual adoption, usage, or ROI:

- https://learn.microsoft.com/microsoft-365/copilot/copilot-control-system/measurement-reporting — Copilot Control System measurement & reporting pillar: operational reports (admin center), strategic reports (Copilot Dashboard), customizable Viva Insights reporting; readiness/adoption, productivity impact, business value and ROI. Supports the Copilot value and ROI steps.
- https://learn.microsoft.com/viva/insights/org-team-insights/copilot-dashboard — Copilot Dashboard adoption and impact pages (licensed users), Copilot assisted hours/value; includes a documented metric-computation known issue window. Supports adoption measurement and the "verify metric definitions" caution.
- https://learn.microsoft.com/microsoft-365/admin/activity-reports/microsoft-365-copilot-readiness — Microsoft 365 Copilot readiness/usage report: which users are eligible, license assignment, usage of integrated apps (note up to 72h latency). Supports license-to-value and readiness steps.
- https://learn.microsoft.com/microsoft-365/admin/adoption/ai-adoption-score — AI adoption category in Adoption Score: methodology (target ~3 days/week active Copilot use), tenant-level scoring. Supports adoption baseline/target framing.
- https://learn.microsoft.com/microsoft-365/fasttrack/microsoft-365-copilot — FastTrack guidance for Copilot readiness, adoption (Copilot Success Kit, Copilot Analytics), and measuring impact; includes explicit out-of-scope items. Supports adoption-program scoping and pushback.

## Grounding rule

Official documentation explains how Microsoft adoption and Copilot reporting work. It does not prove the user's actual license utilization, adoption score, productivity impact, or ROI. Always require evidence from the user's Microsoft 365 admin center usage reports, Adoption Score, or Copilot Analytics for current-state claims, and note metric latency and known data-issue windows. Never present a metric formula without verifying it is current.
