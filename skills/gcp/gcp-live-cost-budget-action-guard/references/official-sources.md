# Official Sources — GCP Live Cost Budget Action Guard

Authoritative GCP documentation for Cloud Billing, budgets, committed-use discounts, and quota management.

## Core References

- **Cloud Billing Budgets** — https://cloud.google.com/billing/docs/how-to/budgets
  How to create, configure, and manage budgets with alert thresholds and programmatic notifications via Pub/Sub.

- **Committed Use Discounts (CUDs)** — https://cloud.google.com/docs/cuds
  Overview of resource-based and spend-based CUD contracts, commitment terms, and how to purchase and view commitments.

- **Requesting Quota Increases** — https://cloud.google.com/compute/resource-usage#request_quotas
  How to view current quota usage and submit quota increase requests through Cloud Console or the Quotas API.

- **Cloud Billing IAM Roles** — https://cloud.google.com/billing/docs/how-to/billing-access
  Complete reference for billing IAM roles including `billing.admin`, `billing.viewer`, and `billing.costsManager`.

- **Budget Notifications via Pub/Sub** — https://cloud.google.com/billing/docs/how-to/budgets-programmatic-notifications
  How to configure programmatic budget alerts and automated responses using Cloud Functions.

- **Cloud Billing Reports** — https://cloud.google.com/billing/docs/how-to/view-invoice
  How to view cost reports, export billing data to BigQuery, and analyze spending trends.

- **Service Usage and Quotas API** — https://cloud.google.com/service-usage/docs/access-control
  IAM roles and API reference for managing quotas programmatically.

- **CUD Analysis and Recommendations** — https://cloud.google.com/billing/docs/how-to/cud-analysis-resource-based
  How to use the CUD Analysis tool to evaluate commitment efficiency and identify over- or under-commitment.
