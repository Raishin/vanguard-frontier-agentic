## Grounding rule

Official documentation explains GCP billing anomaly detection, quota system behavior, SCC finding severity, and SLO monitoring. It does not prove the user's current cost delta, quota utilization levels, pipeline status, or SCC finding ownership. Prefer live evidence (sanitized billing report, quota dashboard, SCC findings export) for current-state claims.
