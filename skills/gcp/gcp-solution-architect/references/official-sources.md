## GCP documentation

Use these as starting points, not as proof of the user's live GCP state:
- https://cloud.google.com/architecture/framework

## Grounding rule

Official documentation explains GCP service behavior. It does not prove the user's current project, folder, org policy, quota, resource configuration, IAM binding, pricing, or operational state. Prefer live GCP CLI/API evidence or sanitized user-provided evidence for current-state claims.
