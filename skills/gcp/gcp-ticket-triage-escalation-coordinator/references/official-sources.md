## Grounding rule

Official documentation explains GCP support SLA tiers and monitoring service behavior. It does not prove the user's current incident scope, alert root cause, or platform status. Prefer live evidence (status.google.com check, sanitized monitoring output) over documentation-based assumptions during active incidents.
