## Grounding rule

Official documentation explains GCP Cloud Build and Cloud Deploy service behavior. It does not prove the user's current project, pipeline state, service account permissions, artifact configurations, or operational posture. Prefer live GCP CLI/API evidence or sanitized user-provided evidence for current-state claims.
