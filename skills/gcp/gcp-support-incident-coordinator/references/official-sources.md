# Official sources

Use this reference only when you need source grounding for GCP support SLA, Managed Incident process, and status page behavior or the detailed source list.

## Google Cloud documentation

Use these as starting points, not as proof of the user's live GCP incident state:
- https://cloud.google.com/support/docs/overview
- https://cloud.google.com/support/docs/severity-definitions
- https://status.google.com/
- https://cloud.google.com/support/docs/managed-incident

- https://cloud.google.com/support/docs/best-practices

## Grounding rule

Official documentation explains GCP support SLA tiers and Managed Incident behavior. It does not prove the current incident scope, whether a Managed Incident has been declared, or the user's TAM contact availability. Prefer live evidence (status.google.com check, support portal case status) over documentation-based assumptions during active support incidents.
