## Grounding rule

Official documentation explains GCP networking behavior. It does not prove the user's current VPC configuration, firewall rules, BGP session state, quota, pricing, or operational state. Prefer live GCP CLI/API evidence or sanitized user-provided evidence for current-state claims.
